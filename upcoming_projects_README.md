## Multimodal Digital Epidemiology Capstone  
*CSCI E-597: Master's Degree Capstone Project*  

- Designing a **multimodal, multilingual, real-time digital early-warning system** for Highly Pathogenic Avian Influenza (H5N1).  
- Integrating **text, emoji, and image-associated signals** from social media and search data to detect early-warning periods preceding official outbreak recognition.  
- Comparing **linear vs non-linear time-series models** (e.g., regression, LSTM, GRU, Transformer-based architectures).  
- Incorporating **simplified mechanistic frameworks** to contextualize digital signals relative to institutional outbreak awareness.  
- Building an **agentic AI–driven data pipeline** to automate ingestion, preprocessing, translation, labeling, and monitoring.  
- Evaluating performance using **AUROC, F1 score, precision–recall, and lead-time metrics**.  
- Deploying a **demonstration-level real-time system** with logging and reproducibility guarantees.
